# Codex용 세 가지 스킬

이 포크에서는 디버깅, 완료 전 검증, 코드 리뷰 세 가지만 설치해 사용할 수 있습니다. 작업 규모에 따라 아래 방식을 선택하며, 사용자 요청과 프로젝트의 기존 지침을 우선합니다.

| 작업 | 실행과 리뷰 | 진행 기록 |
| --- | --- | --- |
| 범위가 명확한 작은 수정 | 현재 세션에서 수정하고 영향받은 동작을 확인합니다. | 별도 파일이 필요하지 않습니다. |
| 여러 단계가 얽힌 기능, 원인 추적이 필요한 버그, 비용을 줄이고 싶은 작업 | 현재 세션에서 순서대로 구현합니다. 단계별로 필요한 검사를 하고 마지막에 전체 변경을 리뷰합니다. | 기존 계획이나 조사 기록을 단계가 끝날 때마다 갱신합니다. |
| 독립적인 작업을 나눌 수 있고 위임을 요청한 경우 | 작업마다 새 구현 에이전트를 사용합니다. 각 결과를 요구사항과 코드 품질 두 측면에서 리뷰한 뒤 전체 통합 결과를 확인합니다. 작업별로 다른 관점을 얻는 만큼 에이전트 호출과 토큰이 더 필요합니다. | 담당 세션이 각 작업의 리뷰·검증 결과와 다음 작업을 같은 파일에 기록합니다. |

긴 작업에 기록이 없으면 작업별 파일 하나를 만듭니다. 재개할 때는 기록에 적힌 결과를 현재 코드와 대조하고, 바뀐 의존성이 영향을 준 검사만 다시 실행합니다. 독립 리뷰는 위임 권한과 도구가 있을 때 진행하며, 직접 리뷰한 경우에는 결과에 표시합니다. 실행 방식별 세부 절차와 기록 예시는 [실행 및 재개 가이드](skills/requesting-code-review/references/execution.md)에 있습니다. 두 방식은 원본의 [직접 실행](../../skills/executing-plans/SKILL.md)과 [작업별 위임](../../skills/subagent-driven-development/SKILL.md)을 세 스킬에 맞게 조정했습니다.

## 설치

Codex에서 다음 요청으로 이 프로필을 설치할 수 있습니다.

```text
$skill-installer GitHub 저장소 UncleKowi/superpowers의 main에서 다음 세 경로를 설치해줘.
profiles/codex/skills/systematic-debugging
profiles/codex/skills/verification-before-completion
profiles/codex/skills/requesting-code-review
```

이미 같은 이름의 스킬을 쓰고 있다면 기존 설치 위치를 확인하고 그 위치에서 업데이트하세요. 프로젝트 전용 규칙은 해당 프로젝트의 `AGENTS.md`에서 관리합니다. 스킬을 업데이트한 뒤 새 Codex 세션의 사용 가능 목록에서 세 이름을 확인할 수 있습니다.
